## 修掉一条日期依赖的用例（01:32）

- 跨过零点后跑全量测试，`test/schedule_page_test.dart` 的「动态课程表首屏渲染」挂了：`Found 0 widgets with text "周六 10/17"`。10/16 周五还是绿的。
- **根因是用例的问题，不是页面**：网格只渲染**有课的星期列**——resolver 里 `days = {数据中 courses 出现过的星期} ∪ {本周有条目的星期}`（`timetable_resolver.dart:413`），2615 班没有周六日的课，所以周末必然没有对应列。而这条用例写死断言「今天那一列在表头」（`test/schedule_page_test.dart:53`），于是**只在周一到周五能过**。
- **修法**：改用 `TimetableResolver(data).resolve(realWeek).days` 反推 —— 逐个断言表头含该列（`weekdayLabel(day) m/d`），再断言「今天落在本周且本周确有此列」时才出现今天的标签。与运行日期无关，周末 / 假期 / 无课周都能过。`weekdayLabel` 从 `widgets/timetable_grid.dart` 导入。
- **教训（写进用例注释）**：凡是「按真实系统日期」算期望值的断言，都要问一句「换一天还成立吗」；尤其是断言「今天有 X」时，先确认 X 的存在性是否依赖日期。全仓库只有这一处 `DateTime.now()`，已扫过。
