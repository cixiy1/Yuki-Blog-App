## 周三「Java + 晚自习」同格 —— 双端取格规则不一致（00:30）

- 用户报：「app 的周三一节 Java 和晚自习，但其实是有课就没有晚自习了」。
- **先核实事实**（拿 App 自己的 resolver 跑探针，逐周逐格打印）：
  - 周三 9-10 **本学期只有第 4 周有 Java**（`c10`，且该次换教室到强能楼505）；第 4 周该格是 Java、**没有**晚自习 —— 与口径一致。

  - 所以用户看到的那张「Java」是课程 `c10` 的**「非本周」灰色占位卡**，不是本周的课。
- **真问题不是数据、也不是判定逻辑，而是两端取格规则不一致**：
  - 博客 `render()` 用 `res.entries.forEach(function(e){ if (e.day===d && e.slot===sk) cell = e; })` —— **后者胜出**，而晚自习条目最后入数组 ⇒ 灰卡被晚自习顶掉，一格只显示晚自习。
  - App 把同格所有条目**纵向堆叠** ⇒ 显示「Java 非本周 + 晚自习」两格，且整行被撑成两格高（其它列留白），看起来就像「有课还有晚自习」。
  - 实测确认：博客第 7 周网格 `非本周: 2`（c02 / c09），App 是 3 张灰卡（多出的正是 c10）；博客周三 9-10 是 `is-study` 单卡。
- **修法（两端同一条规则：一格只显示一条）**：
  - App `ResolvedEntry` 新增 `cellPriority`：`study → 1`、`off → 0`、其余（on / add / cancel）`→ 2`；`resolve()` 建 `cells` 索引时按优先级取一条，**同级后者胜出**（与博客 forEach 语义等价）。
  - 博客把取格规则从「碰巧后者胜出」抽成显式 `cellRank`（`e.selfStudy ? 1 : (e.active||e.cancelled) ? 2 : 0`），**全 19 周逐格输出与改动前逐字节一致**（纯显式化，无行为变化）。
  - 网格里多条堆叠的渲染路径保留作兜底，注释写明「解析器已保证一格一条」。
- **验证**：App 单测 **91 项全绿**、`flutter analyze` 零告警；写了「App `_probe_cells.dart` 输出 ⟷ 博客 harness JSONOUT 输出」的逐格对拍脚本，**全 19 周 × 全时段行 × 全星期 0 真实差异**（App 只是不渲染纯空列，如 W7 的周六，属预期）。修后逐周结果（两端一致）：W4 周三 9-10＝Java(有课) 无晚自习；W5 / W13 / W14＝c10 灰格且无晚自习；其余周＝晚自习 @强能楼812；W6 周三 5-6 / 9-10 被「返校」顶掉。

- **回退**：`git revert --no-commit d899e89 f3d5121 113bba3 d1cda86`（时间倒序合成一个 revert 提交 94de3de），撤掉 iOS 风玻璃标题栏整套（含 schedule/setting 页头去重、版本号回 1.4.2+11）。
- **网页版配方**（读 `src/components/layout/Navbar.astro` + `src/styles/navbar.css` + `src/styles/variables.styl`）：semifull 模式 = 贴顶态**完全透明**（无背景/模糊/阴影/边框）→ 滚动 `scrollTop > 50` → `card-bg` 45% + `backdrop-filter: blur(20px)` + 两条 box-shadow 细线（顶高光 亮 rgba(255,255,255,.18)/暗 .06；底发丝 亮 rgba(0,0,0,.06)/暗 rgba(255,255,255,.10)）；过渡 0.36s cubic-bezier(0.22,1,0.36,1)（== Flutter `Curves.easeOutQuint`）；监听 scroll + rAF 节流。App 端 `glassAppBar()`/`GlassAppBarLayer`/`glassProgressOf()`（二值化：>50px → 1）逐条对齐，提交 658a9a9 + 93ce017。
- **全屏模糊根因（连踩两次，用户两次反馈都是旧包）**：`AppBar.flexibleSpace` 在 `Align(topCenter)` + `Stack(fit: passthrough)` 里，约束经 loosen 后高度上限不是工具栏高；`Stack(fit: StackFit.expand)` + `Positioned.fill` 吃下无界高度 → `BackdropFilter` 模糊层被撑到**全屏**。**修法**：flexibleSpace 内容先过 `SizedBox(height: kToolbarHeight + MediaQuery.paddingOf(context).top)` 钉死高度（`_toolbarSized`），Stack 只在其内铺满；标题用 `Positioned(top: top, height: kToolbarHeight)` 定位。**回归测试**：`getSize(find.byType(BackdropFilter)).height == kToolbarHeight` 且远小于屏高（提交 3c8e115）。
