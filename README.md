# Yuki-Blog App

The mobile app of [Yuki-blog](https://yiyu14.top), built for Class 2615.

- Dynamic class timetable with weekly overrides, synced from the blog's online data source (yiyu14.top, with GitHub raw and jsDelivr as fallbacks; offline falls back to the bundled asset).
- Built with Flutter.

## Development

```bash
flutter pub get
flutter analyze
flutter test
```
